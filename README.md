# 💬 Real-Time Chatroom Application

### 🧰 Tech Stack
React.js | Spring Boot | WebSockets (STOMP/SockJS) | MongoDB

### 📖 Overview
A full-stack real-time messaging application enabling instant communication across multiple chat rooms.  
Built with **React.js** for a responsive frontend and **Spring Boot** for backend REST APIs.  
Integrated **WebSockets** for live bi-directional messaging and room-based conversations.

### 🚀 Features
- Real-time message delivery with WebSocket integration  
- Create, join, and manage chat rooms dynamically  
- MongoDB persistence for chat history and users  
- REST APIs for user and room management  
- Simple responsive UI built with React  

### ⚙️ Setup Instructions
1. Clone the repository:  
   ```bash
   git clone https://github.com/jainil510/Realtime-Chatroom-Application
2. Start backend (Spring Boot):
   mvn spring-boot:run

3. Start frontend (React):
   npm start

4. Open http://localhost:3000 in browser.
   
5. 🧠 Learning Outcomes
- Implemented WebSockets for real-time communication
- Used Spring Boot REST APIs with MongoDB integration
- Learned full-stack integration between React & Spring Boot
